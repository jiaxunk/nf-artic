# Domain Documentation

This repository uses a **single-context** architecture.

## Layout

- `CONTEXT.md` — Core pipeline architecture, domain models, and component boundaries.
- `docs/adr/` — Architectural Decision Records (ADRs) capturing significant technical decisions.

## Consumer Rules

- Read `CONTEXT.md` when onboarding or making changes that span across workflow modules or pipeline stages.
- Consult `docs/adr/` for context on previous architectural decisions.
- Add new ADRs in `docs/adr/` using sequential numeric prefixes (e.g., `docs/adr/0001-init.md`).
