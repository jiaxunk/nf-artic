# Issue Tracker

Issues are tracked using **GitHub Issues** in the repository [jiaxunk/nf-artic](https://github.com/jiaxunk/nf-artic).

## Tooling

- CLI: `gh`
- Repository: `jiaxunk/nf-artic`

## Conventions

- Issues are created and managed via the GitHub CLI (`gh issue create`, `gh issue list`, `gh issue view`).
- External Pull Requests are not treated as triage request surfaces by default.
